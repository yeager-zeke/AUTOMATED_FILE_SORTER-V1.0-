# AUTOMATED_FILE_SORTER-V1.0-
A Python automation tool that keeps messy folders organized by automatically sorting files into categorized folders. Since this is only the first version it only supports 5 basic filetypes

# Project name-  automated file sorter/organizer

# project need:
-many people store their files which have different extensions randomly without any properly labelled folder.
-this randomness in saving of the files can lead to chaos when the files are actually needed, that's exactly where the need for sorting the files comes in.
-However, sorting many files off several different file types can be time taking and confusing.

# WHAT DOES THE PROGRAM DO:-

-it takes the path of the folder, which needs to be organized as input.
-it searches for same/similar filetypes in the whole folder.
-append the same/similar types of file into one sub-folder.

# technologies used:-

1.)Python: this script is fully written in python language because of its vast library and comprehensive code writing.

2.) ChatGPT: for understanding the program flow and helping in debugging of the program.

3.) OS Module: used for engaging with the operating system things such as creating/managing folders, drives, files 

4.) Shutil Module: used for shifting files from one directory to another.
